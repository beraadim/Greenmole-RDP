# Deployment diagram

`deployment-architecture.svg` is original documentation artwork for Greenmole
and Greenmole RDP, shared unchanged between both repositories. Edit the SVG
directly and keep the two copies in sync. It uses generic deployment labels and
contains no production addresses, credentials, or configuration.
