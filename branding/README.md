# Greenmole RDP artwork

The Greenmole RDP mascot is the existing Greenmole project's cute green mole.
The original PNG is copied without modification from
[Greenmole](https://github.com/beraadim/Greenmole), at
`client/guacamole/src/main/frontend/src/images/greenmole.png`.

Original PNG SHA-256:
`5c1cb410e7f474ad971f29cfd09895d1413a58abbe9cb038c1afd1e38a6729a7`.

The artwork is distributed under the Greenmole repository's Apache License 2.0.
Its [license](LICENSE) and [original notice](NOTICE) are retained here and bundled
with the application. This asset notice does not change Greenmole RDP's existing
GPLv3 source license or third-party code licenses. The mascot is not derived from
the Apache Guacamole logo.

Run `bash tools/build-brand-icons.sh` on macOS to reproduce the application ICNS,
PNG sizes, color menu-bar icon and multi-resolution ICO. Resizing preserves the
original alpha channel; the original artwork is unchanged. The frontend uses
the existing Greenmole 256-pixel derivative of this same image.
